# kdcma-abundant-light

**풍요로운 빛**은 한국어·영어·스페인어로 제공되는 20과 구성의 인터랙티브 웹 성경공부 교재입니다.

## 주요 기능

- 한국어·English·Español 즉시 전환
- 각 과의 수업과 복습 단계
- 객관식, 복수 선택, 빈칸, 짝 맞추기, 단답형, 서술형 문항
- 문항별 참고 답 확인
- 브라우저 기기 안 자동 저장
- 개인 답안 JSON 내려받기
- 성경 연대표와 학습용 지도
- 데스크톱·태블릿·모바일 반응형 화면
- 인터넷 연결 없이 사용 가능

영어판의 성경 표기는 NIV, 스페인어판은 NVI 기준으로 통일했습니다.

## 실행 방법

`index.html`을 웹 브라우저에서 열면 바로 사용할 수 있습니다. 별도의 설치나 서버가 필요하지 않습니다.

로컬 웹 서버를 사용하는 경우 이 폴더를 문서 루트로 지정하면 됩니다. 모든 파일은 정적 파일이므로 GitHub Pages에서도 사용할 수 있습니다.

## 파일 구성

- `index.html` — 교재 화면
- `styles.css` — 반응형 디자인
- `app.js` — 언어 전환, 답 저장, 문항 상호작용
- `course-data.js` — 3개 언어의 20과 교재 데이터
- `assets/` — 과별 삽화, 지도, 연대표
- `build-manifest.json` — 빌드 및 검수 정보

관리자 편집 실험 기능은 이 학생용 완성판에 포함하지 않았습니다.

## 검수 상태

한국어·영어·스페인어 각 20과에 대해 문항과 답칸의 대응, 복합 질문 분리, 객관식 정답 키, 빈칸 구조, 언어별 성경 버전, 지도·연대표 및 이미지 경로를 자동 검사했습니다. 안내문·기도문·마무리 문단에 불필요한 답칸이 생기지 않도록 별도 검증 규칙도 적용했습니다.
